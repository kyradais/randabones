# Randabones
A web-based 2D bone animation editor inspired by Spine2D.

    cd randabones
    npm start        # then open http://localhost:3000

No `npm install` needed (zero dependencies). For features that are not working yet, see `CHECKLIST.md`.

Shortcuts: V select · B create bone · T translate · R rotate · H pan canvas · K set key · Space play/pause · Del delete bone.
